# DevPulse — Radar de Inteligência Artificial

Projeto didático para Tecnologia para Frontend Avançado.

## Já incluído no scaffold
- Vite + React + TypeScript
- MUI, tema claro/escuro e layout
- React Router com as rotas principais
- Contextos de tema e favoritos
- Tipos TypeScript da API
- Instância Axios configurada
- Componentes de carregamento, erro e estado vazio
- Páginas e arquivos TODO para desenvolvimento em sala

## Desenvolvido com a turma
1. Serviço de pesquisa e consulta individual
2. SearchBar
3. NewsCard
4. Listagem com useState e useEffect
5. Detalhes com useParams e useEffect
6. Favoritos com useContext

## Executar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
